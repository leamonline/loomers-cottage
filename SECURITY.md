# Security and privacy

Treat this repository as public regardless of its current visibility. Publish only reusable software, synthetic fixtures, generic contracts and sanitised documentation. Keep actual home configuration and deployment evidence in owner-controlled private storage, not GitHub.

Never commit credentials, tokens, webhook URLs, private hostnames, household addresses, actual entity/device/account identifiers, live configuration fingerprints, raw HA storage, occupancy history, camera media, backups or encryption keys. The same rules apply to issue descriptions, comments, pull requests, CI logs and artifacts. Use placeholders and synthetic fixtures. No live secrets in client code; no public CDN or analytics.

Review all source imports and diffs before publishing. Run repository privacy checks and secret scanning, including history where feasible. If exposure is suspected, report privately to the owner and rotate affected secrets outside Git; changing visibility does not erase prior exposure.

Security and safety automations run independently. Changes to locks, access, smoke, ventilation safety and EV require explicit scope approval. No automated deployment from public CI. Recovery and release gates remain binding.
