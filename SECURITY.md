# Security and privacy
Private repository only. Never commit credentials, tokens, webhook URLs, private hostnames, household addresses, raw HA storage, location history, camera media, backups or encryption keys. Use placeholders and synthetic fixtures. No live secrets in client code. No public CDN or analytics. Security and safety automations run independently; changes to locks, access, smoke, ventilation safety and EV require explicit scope approval. Report suspected exposure privately to owner; rotate affected secrets outside Git. Review every import and diff before commit.
