# Release roadmap
All dates are estimates; gates override schedule.
| Gate | Scope | Exit evidence |
|---|---|---|
| G0 | Recovery and governance | verified encrypted off-host backup, kit, isolated restore and source hashes |
| F1 | Bedroom TV dependencies | exact approved diff, CEC wake/sleep verification, historical statistics preserved |
| F2 | Foundation reliability | entity bindings, warning accuracy, individually approved fixes |
| P2.1 | Natural Cottage Lab | fixture-only candidate, browser tests, Apple-device acceptance |
| C1 | Live read mirror | approved bindings, freshness, all routes, native fallback |
| C2 | Context and data contract | factual concierge, occupancy uncertainty, priority, source provenance |
| C3 | Controls and overrides | separate per-domain allowlist, restart/manual override tests |
| E1 | Energy | supplier reconciliation, EV slots and consumption, forecast uncertainty |
| H1 | Health | actionable diagnostics, nonduplicated escalation, no automatic repair |
| L1 | Advisory learning | approved scope, local aggregates, >=21 days, >=14 observations, >=80% coverage, >=70% agreement |
| R1 | Production | seven-day parallel trial, performance, recovery, explicit cutover approval |
| L2 | Optional adaptation | per-policy approval, bounded changes, rollback and cooldown |
